# Animations · 随机与涌现

[![Checks](https://github.com/CAUCHY-zzz/animations/actions/workflows/check.yml/badge.svg)](https://github.com/CAUCHY-zzz/animations/actions/workflows/check.yml)

两个可交互的数学与群体行为可视化实验：**二维／三维随机游走**和**鸟群涌现**。页面使用原生 JavaScript 与 Canvas 绘制，HTML 内包含全部样式和动画代码，可以离线运行。

## 开始使用

1. 点击仓库的 **Code → Download ZIP**，下载并解压。
2. 用现代浏览器打开 `index.html`，选择一个动画。
3. 也可以直接打开以下任意 HTML 文件。

| 动画 | 源文件 | 主要功能 |
| --- | --- | --- |
| 随机游走 | [random-walk.html](random-walk.html) | 二维／三维切换、速度调整、坐标刻度、缩放与旋转 |
| 鸟群涌现 | [鸟群涌现.html](鸟群涌现.html) | 持续仿真、局部规则调节、扰动、隼与邻居观察 |

GitHub 的文件页面显示源码。要运行动画，请下载文件后用浏览器打开。

## 随机游走

每一步独立、等概率地沿一个坐标轴前进一个单位：二维中有 4 个方向，三维中有 6 个方向。画面显示累计步数、当前坐标和运动轨迹。

| 操作 | 行为 |
| --- | --- |
| 切换二维／三维 | 当前维度从原点重新开始，步数和轨迹归零；仅当前维度运行 |
| 速度滑块 | 调整为每秒 1–60 步 |
| 坐标系精度 | 自动选择刻度，或设定每格坐标单位 |
| 滚轮、双指或 `+` / `−` 按钮 | 缩放当前视图 |
| 三维画面拖动 | 旋转三维视角 |
| 点击画布后按 `+` / `−` | 键盘缩放 |
| 点击三维画布后按方向键 | 键盘旋转 |
| 点击画布后按 `Home` | 恢复当前视图的缩放与三维朝向 |

动画不设置总步数上限。轨迹使用固定容量缓冲区，显示最近 10,000 步，累计步数和位置继续更新。切换时保留速度、坐标精度和各维度的缩放设置。

## 鸟群涌现

鸟群由 Boids 风格的局部规则驱动。每只鸟只响应感知范围内最近的最多 **7 只邻居**，不使用领头鸟或预设的整体飞行路径。

- **避碰**：远离过近的邻居。
- **对齐**：逐渐接近邻居的平均飞行方向。
- **聚拢**：向邻居所在的局部位置靠近。

边界约束、微小随机扰动和可选的隼也会影响个体运动。这里的模型用于观察局部互动与整体队形的关系。

| 操作 | 行为 |
| --- | --- |
| 暂停／空格键 | 暂停或继续；聚焦输入控件时空格由控件处理 |
| 重新开始 | 生成新的初始状态 |
| 鸟数 | 选择 1,200、2,400、3,200 或 4,200 只鸟，并重新开始 |
| 避碰、对齐、聚拢滑块 | 调整三条规则的强度 |
| 点击画面 | 投放局部扰动；开启“观察邻居”后改为选择观察对象 |
| 隼 | 开启或关闭捕食者扰动 |
| 观察邻居 | 显示选中鸟与局部邻居的关系 |
| `H` / 控制按钮 | 显示控制面板 |
| 规则 / 全屏 | 查看模型说明，或进入浏览器全屏模式 |

仿真持续演化，切到后台标签页时暂停推进，返回后继续。设备性能较低时，可减少鸟数。


## 开发与检查

打开动画无需 Node.js。修改源码并运行自动检查时，使用 **Node.js 22 或更高版本**。

```sh
npm run check
npm test
```

检查脚本没有第三方依赖，无需 `npm install`。测试覆盖随机游走的维度切换与轨迹容量，以及鸟群的邻居选择、局部规则、速度边界和持续演化。Canvas 的实际显示、触摸与浏览器全屏效果仍需在浏览器中检查。

### 可选：使用 GitHub Pages

仓库已有 `index.html`，可以作为静态站点入口。在 **Settings → Pages** 中选择 **Deploy from a branch**，使用 `main` 分支的根目录 `/ (root)`，然后保存。部署成功后的访问地址以 Pages 设置页面为准。

配置步骤见 [GitHub Pages 官方文档](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。
