两个 Codex 聊天中的动画成品与对话记录。HTML 文件包含动画代码，下载后用现代浏览器直接打开即可运行，无需安装依赖。

## 二维／三维随机游走

全屏持续运行，通过右下角控件切换二维和三维、调节速度与坐标轴刻度。二维支持缩放；三维支持旋转与缩放。切换维度后从原点重新开始。为限制内存，轨迹保留最近 10,000 步，累计步数持续增加。

[早期二维动画预览](random-walk/random-walk.gif)。此 GIF 为早期版本，最终功能以 HTML 为准。

## 鸟群动画与涌现

每只鸟根据附近最多 7 只邻居的避碰、对齐和聚拢规则运动，整体队形由局部互动形成。支持持续运行、参数调节、局部扰动、隼和邻居观察。
